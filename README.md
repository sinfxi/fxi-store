# درس‌یار — همراه هوشمند یادگیری در تلگرام

**درس‌یار** یک ربات فارسی برای تمرین، مرور و یادگیری فعال است. دانش‌آموز می‌تواند از منو استفاده کند، سؤالش را عادی بنویسد و بدون نیاز به حفظ‌کردن دستورها بین معلم هوشمند، آزمون‌ها و ابزارهای مطالعه جابه‌جا شود.

## چرا درس‌یار؟

- **معلم هوشمند فارسی:** توضیح مرحله‌به‌مرحله، مثال قابل‌فهم، جمع‌بندی و پیشنهاد تمرین؛ با اتصال کلید Groq یا OpenAI.
- **آزمون سریع و آزمون ۵ سؤالی:** پاسخ چهارگزینه‌ای، بازخورد و امتیاز نهایی.
- **فلش‌کارت موضوعی:** مرور فعال، دیدن پاسخ و خودسنجی «بلدم / دوباره مرور کنم».
- **کمک‌درسی و جستجو:** پیدا کردن نتیجه‌های مرتبط با موضوع درسی و نمایش آن‌ها در خود ربات؛ دسترسی و کیفیت نتیجه‌ها به سرویس جستجوی بیرونی وابسته است.
- **چالش روزانه:** تمرین کوتاه برای حفظ پیوستگی یادگیری.
- **گزارش پیشرفت:** شمارنده‌ی پاسخ‌ها، پاسخ‌های درست و خودسنجی کارت‌ها.
- **برگه‌ی فرمول‌ها و واژه‌ی انگلیسی:** مرور سریع نکته‌های پرکاربرد.
- **برنامه‌ی مطالعه و تمرکز:** تقسیم زمان به بخش‌های قابل‌مدیریت همراه با استراحت.
- **تعامل دکمه‌ای:** مسیرهای اصلی از منوی ربات در دسترس‌اند و برای سؤال آموزشی می‌توان مستقیماً پیام نوشت.

## شروع استفاده

1. ربات را در تلگرام باز کن و **Start** را بزن.
2. از منوی اصلی، «معلم هوشمند»، «آزمون»، «فلش‌کارت» یا «برنامه مطالعه» را انتخاب کن.
3. برای پاسخ بهتر، پایه و درس را همراه سؤال بنویس؛ مثلاً: «پایه هشتم، ریاضی: چرا منفی در منفی مثبت می‌شود؟»
4. بعد از توضیح، از دکمه‌های تمرین مشابه یا خلاصه‌ی ساده برای ادامه‌ی یادگیری استفاده کن.

## محتوای آموزشی

مجموعه‌ی فلش‌کارت‌ها شامل ۹۲ کارت در ۲۴ موضوع است؛ از جمله ریاضی، فیزیک، شیمی، زیست‌شناسی، فارسی، نگارش، عربی، انگلیسی، تاریخ، جغرافیا، اقتصاد، منطق، برنامه‌نویسی و روش مطالعه. این مجموعه نقطه‌ی شروع است و به‌معنای پوشش کامل تمام پایه‌ها، فصل‌ها یا کتاب‌های رسمی نیست.

## راهنمای توسعه و استقرار

Python 3.11 یا بالاتر پیشنهاد می‌شود.

```bash
python -m venv .venv
# ویندوز: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

در Railway، سرویس را به مخزن متصل کن و این متغیرها را در بخش Variables تنظیم کن:

- `BOT_TOKEN` — توکن ربات، الزامی
- `ADMIN_ID` — شناسه عددی مدیر
- `GROQ_API_KEY` — اختیاری؛ در صورت تنظیم بر OpenAI اولویت دارد
- `GROQ_MODEL` — پیش‌فرض `llama-3.3-70b-versatile`
- `OPENAI_API_KEY` — اختیاری، جایگزین Groq
- `OPENAI_MODEL` — پیش‌فرض `gpt-4o-mini`
- `DB_PATH` — مسیر پایگاه داده SQLite؛ پیش‌فرض `./data/studybot.db`

Start Command در Railway: `python bot.py`. ربات از Telegram polling استفاده می‌کند و به دامنه‌ی عمومی نیاز ندارد.

## حریم خصوصی و استفاده مسئولانه

- توکن ربات و کلیدهای API را در کد یا GitHub قرار نده؛ فقط در متغیرهای محیطی نگه‌دار.
- متن سؤال‌ها برای ساخت گزارش پیشرفت در SQLite ذخیره نمی‌شود؛ آمار آموزشی پایه ذخیره می‌شود.
- اگر معلم هوشمند فعال باشد، متن سؤال برای تولید پاسخ به ارائه‌دهنده‌ی مدل هوش مصنوعی ارسال می‌شود. اطلاعات شخصی، رمز عبور یا کدهای ورود نفرست.
- نتیجه‌های جستجو ممکن است ناقص یا موقتاً در دسترس نباشند.
- پاسخ‌های هوش مصنوعی ممکن است اشتباه باشند؛ آن‌ها را با کتاب درسی و راهنمایی معلم بررسی کن.
- پیش از استفاده‌ی گسترده در مدرسه، نسخه‌ی مستقر، متغیرهای امنیتی، هزینه‌ی API و سیاست حریم خصوصی را آزمایش و بازبینی کن.
