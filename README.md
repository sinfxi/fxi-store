# درس‌یار | ربات کمک‌درسی تلگرام

ربات فارسی دانش‌آموزی با توضیح مفاهیم، آزمون چهارگزینه‌ای، فلش‌کارت و برنامه‌ریزی مطالعه. اگر `OPENAI_API_KEY` تنظیم شود، پاسخ‌های آموزشی با مدل هوش مصنوعی ارائه می‌شود؛ در غیر این صورت فرمان‌های آموزشی پایه همچنان فعال‌اند.

## قابلیت‌ها
- `/start` و `/help`: راهنما
- `/ask <سوال>`: پرسش آموزشی (با کلید اختیاری OpenAI)
- `/quiz`: آزمون چهارگزینه‌ای
- `/flashcards`: فلش‌کارت‌های نمونه
- `/plan`: برنامه‌ی پیشنهادی مطالعه
- `/privacy`: توضیح حریم خصوصی
- `/stats`: آمار ساده، فقط برای مدیر تعیین‌شده

## راه‌اندازی محلی
Python 3.11+ پیشنهاد می‌شود.

```bash
python -m venv .venv
source .venv/bin/activate  # ویندوز: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
# مقادیر را در .env قرار بده
python bot.py
```

## استقرار در Railway
1. در Telegram با `@BotFather` یک توکن جدید بساز؛ توکنی که قبلاً در چت منتشر شده را لغو کن.
2. در Railway سرویس را به این مخزن متصل کن.
3. در Variables مقدارهای `BOT_TOKEN` و `ADMIN_ID` را تنظیم کن؛ `OPENAI_API_KEY` اختیاری است.
4. Start Command را روی `python bot.py` بگذار. برنامه از polling استفاده می‌کند و به دامنه‌ی عمومی نیاز ندارد.

## متغیرها
- `BOT_TOKEN`: توکن تازه‌ی ربات (الزامی؛ هرگز در کد/گیت قرار نگیرد)
- `ADMIN_ID`: شناسه‌ی عددی مدیر
- `OPENAI_API_KEY`: اختیاری
- `OPENAI_MODEL`: پیش‌فرض `gpt-4o-mini`
- `DB_PATH`: مسیر SQLite، پیش‌فرض `./data/studybot.db`

## نکات امنیتی و حریم خصوصی
- توکن‌ها فقط در متغیرهای محیطی نگه‌داری شوند.
- ربات پیام‌های گروهی را برای پاسخ آزاد پردازش نمی‌کند؛ در گروه فقط فرمان‌ها.
- برای جلوگیری از هزینه‌ی ناخواسته، پاسخ هوش مصنوعی محدود و rate limit ساده دارد.
- داده‌های محلی فقط شناسه‌ی کاربر و شمارنده‌ی تعامل را ذخیره می‌کنند؛ متن پرسش‌ها ذخیره نمی‌شود.
- این ربات کمک‌آموزشی است؛ پاسخ‌های هوش مصنوعی را با کتاب/معلم بررسی کن.
