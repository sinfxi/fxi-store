# درس‌یار — سامانهٔ یادگیری و مرور در تلگرام

درس‌یار یک ربات آموزشی فارسی است که آزمون، فلش‌کارت، مرور فاصله‌دار، ثبت زمان مطالعه، پیگیری عادت یادگیری و کمک‌درسی را در یک تجربهٔ تلگرامی جمع می‌کند. پروژه در حال توسعه است؛ محتوای کارت‌ها هنوز جایگزین کتاب رسمی یا بانک سؤال بازبینی‌شده برای یک پایه و فصل مشخص نیست.

## امکانات

- **معلم هوشمند فارسی:** توضیح مرحله‌به‌مرحله و تمرین مشابه با Groq یا OpenAI (کلید API اختیاری است).
- **آزمون‌ها:** آزمون چهارگزینه‌ای سریع، آزمون ۵ سؤالی و توضیح پاسخ.
- **بانک فلش‌کارت چندموضوعی:** انتخاب درس، نمایش پاسخ و خودسنجی «بلدم / دوباره مرور کنم»؛ سؤال‌های تکراریِ دقیق پس از نرمال‌سازی حذف می‌شوند.
- **مرور فاصله‌دار:** کارت‌هایی که «بلدم» علامت می‌خورد با فاصله‌های افزایشی برای مرور بعدی زمان‌بندی می‌شوند؛ کارت دشوار برای مرور مجدد زودتر سررسید می‌شود.
- **هدف روزانه و ثبت مطالعه:** تعیین هدف دقیقه‌ای، ثبت جلسه و مشاهدهٔ پیشرفت روز.
- **زنجیرهٔ مطالعه:** محاسبهٔ روزهای پیوستهٔ مطالعه بر اساس جلسه‌هایی که کاربر ثبت کرده است.
- **پروفایل آموزشی:** ذخیرهٔ پایه/مقطع برای شخصی‌سازی تدریجی.
- **گزارش پیشرفت و پنل مدیر:** آمار کلی کاربرها و فعالیت‌های ثبت‌شده، محدود به شناسهٔ مدیر.
- **پنل وب مدیریتی:** داشبورد واکنش‌گرا با آمار کاربران و مطالعه، نمودار ۷ روز اخیر، جستجوی کاربران، خروجی CSV و ارسال پیام همگانی با تأیید نهایی.
- **چالش روزانه، فرمول‌ها، واژگان انگلیسی، برنامهٔ مطالعه و تمرکز.**
- **یادداشت‌های شخصی:** ذخیره، مشاهدهٔ ۱۰ یادداشت اخیر و حذف یادداشت با بررسی مالکیت؛ هر کاربر فقط یادداشت‌های خودش را می‌بیند.
- **تایمر مطالعه:** تایمر زندهٔ ۱ تا ۱۸۰ دقیقه‌ای با اعلان پایان و امکان توقف؛ بعد از پایان می‌توان زمان را با `/done` در آمار ثبت کرد.
- **نکتهٔ مطالعه:** پیشنهاد تصادفی دربارهٔ بازیابی فعال، مرور فاصله‌دار، تمرین و تمرکز.
- **جستجوی کمک‌درسی:** دریافت نتایج جستجوی وب در خود ربات؛ در دسترس بودن نتیجه‌ها به سرویس بیرونی بستگی دارد.

## راه‌اندازی و متغیرها

Python 3.11 یا بالاتر پیشنهاد می‌شود.

```bash
pip install -r requirements.txt
python bot.py
```

در Railway سرویس را به مخزن متصل کن و `python bot.py` را به‌عنوان Start Command قرار بده. پنل وب در همان سرویس و روی پورت `PORT` اجرا می‌شود؛ مسیر سلامت سرویس `/health` است. پس از فعال‌شدن دامنهٔ Railway، داشبورد از `/` یا `/dashboard` باز می‌شود. متغیرهای محیطی:

- `BOT_TOKEN` — الزامی؛ توکن را فقط در Variables نگه‌دار.
- `ADMIN_ID` — شناسهٔ عددی مدیر ربات.
- `GROQ_API_KEY` — اختیاری؛ در صورت وجود بر OpenAI اولویت دارد.
- `GROQ_MODEL` — پیش‌فرض `llama-3.3-70b-versatile`.
- `OPENAI_API_KEY` و `OPENAI_MODEL` — جایگزین اختیاری.
- `DB_PATH` — مسیر SQLite؛ پیش‌فرض `./data/studybot.db`.
- `WEB_ADMIN_EMAIL` — ایمیل/شناسهٔ ورود مدیر پنل وب.
- `WEB_ADMIN_PASSWORD` — رمز عبور پنل؛ فقط در Railway Variables نگه‌داری شود.
- `WEB_SESSION_SECRET` — کلید محرمانه برای امضای نشست‌های ورود؛ عمومی نشود.

## پنل وب مدیریتی

- ورود با ایمیل و رمز عبور انجام می‌شود؛ نشست با کوکی `HttpOnly` و زمان انقضای ۸ ساعته مدیریت می‌شود.
- پس از چند تلاش ناموفق، ورود برای مدتی محدود می‌شود. رمز عبور و کلید نشست را فقط در متغیرهای محرمانهٔ Railway نگه‌دار.
- APIهای مدیریت بدون توکن معتبر پاسخ دسترسی غیرمجاز می‌دهند.
- گزارش‌ها از همان SQLite ربات خوانده می‌شوند؛ شناسهٔ تلگرام، پایه، تعامل‌ها، زمان ثبت‌شده و آمار آزمون نمایش داده می‌شوند.
- خروجی CSV برای گزارش‌گیری و ارسال همگانی پیام با تأیید دوباره در دسترس است. ارسال همگانی برگشت‌پذیر نیست.
- تست‌های خودکار داشبورد در GitHub Actions با هر push و pull request اجرا می‌شوند.

## نگه‌داری داده و استقرار

پروفایل، هدف روزانه، زمان‌های ثبت‌شده و زمان‌بندی کارت‌ها در SQLite ذخیره می‌شوند. در Railway برای ماندگاری داده‌ها پس از استقرار مجدد، یک Volume پایدار به سرویس متصل کن و `DB_PATH` را به مسیری داخل همان Volume تنظیم کن؛ بدون Volume، فایل SQLite داخل کانتینر ممکن است پس از بازسازی از بین برود.

ربات از Telegram polling استفاده می‌کند؛ **نباید بیش از یک نمونه با همان توکن هم‌زمان polling کند**، وگرنه خطای `TelegramConflictError` رخ می‌دهد. یک replica فعال نگه‌دار و هر نمونهٔ قدیمی با همان توکن را متوقف کن.

## حریم خصوصی و محدودیت‌ها

- ربات متن سؤال‌ها را برای آمار محلی ذخیره نمی‌کند؛ اما اگر معلم هوشمند فعال باشد، متن سؤال برای تولید پاسخ به ارائه‌دهندهٔ مدل فرستاده می‌شود.
- شناسهٔ عددی تلگرام، شمارنده‌های یادگیری، مقطع انتخابی، زمان‌های مطالعه و یادداشت‌هایی که خود کاربر ذخیره می‌کند برای قابلیت‌های مربوطه نگه‌داری می‌شوند. یادداشت‌ها در SQLite ذخیره می‌شوند؛ از ارسال رمزها یا اطلاعات حساس خودداری کن.
- برای تولید آمار دقیق، زمان مطالعه را با `/done` ثبت کن؛ این زمان‌سنج خودکار نیست.
- پاسخ هوش مصنوعی و نتایج جستجو ممکن است اشتباه یا ناقص باشند. آن‌ها را با کتاب درسی و معلم بررسی کن.
- محتوای فلش‌کارت فعلی عمومی و چندموضوعی است؛ برای پوشش کامل کتاب‌های رسمی باید محتوا بر اساس پایه، کتاب و فصل به‌صورت جداگانه تولید و بازبینی شود.

## وضعیت

درس‌یار یک پروژهٔ در حال توسعه است. برای استفاده در مقیاس مدرسه، آزمون‌های خودکار، پشتیبان‌گیری پایگاه داده، کنترل دسترسی مدیر و بررسی محتوای آموزشی باید به‌صورت مستمر تکمیل شوند.
